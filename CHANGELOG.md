# Changelog

*Leia em [português](CHANGELOG.pt-BR.md).*

## 1.1.0 — 2026-11-04

### A new layout, built to stay readable

- **New frame:** a sidebar with your character and the sections (keys 1–6), a toolbar with Undo/Redo, the
  pending changes and Save, and a status bar. Game textures, item icons and fonts stay as they were.
- **Character and Server screens are responsive:** they reflow with the window, with comfortable margins and
  text sizes that never get too small or too big. Equipment is a table (armor and vanity side by side), so
  labels can't overlap anymore.
- **The item panel is drawn in vector (SVG),** sharp at any size; long stat lists scroll inside it while the
  actions stay in view.

### Your edits are safe

- **Undo and Redo for every edit,** with a readable description ("Level 48 → 50"); the list of pending
  changes lets you undo back to any point.
- The bare **Z** key no longer throws away every edit.
- **Saving asks for confirmation** and lists what will change. Writing to a player's copy on the server only
  goes through after you confirm the player is offline or kicked.
- Switching character with unsaved edits asks first: save, or discard and switch.

### Fog of war

- **New Fog tab** for local saves: paint what your character has explored over the world map, with a
  reveal/hide brush, adjustable size, reveal/hide all and undo. The brush is adapted from another Enshrouded
  save editor the map is the overview rendered by our Interactive Map.
- The fog can't be edited through the server — a limitation of the game: it lives only in each player's own
  save and is never sent to the server.

### Server

- **Guardian log tab:** read what the Server Guardian writes on the server, including on hosts whose panel
  doesn't show it (BisectHosting); filter to warnings and errors.
- **Guardian status:** the version running on the server and whether it is alive ("running, seen 1 min ago").
- The guardian's observe mode is recognised in both spellings (`"modo": "observar"` and `"mode": "observe"`).

### Languages

- **Five languages:** Português, English, Español, Deutsch and 简体中文. Item and skill names (and skill
  descriptions) use the game's official text in every one; the catalog search finds items by any of the names.
- An unknown system language now starts in English instead of Portuguese.
- Terms match the game: Legendary/Legendário, Grappling Hook/Arpéu, Armor, Upper Body and Lower Body.
- The status bar follows a language switch, and long labels (German) no longer run into the action bar.

### New version notice

- A card in the sidebar tells you when a newer editor is out, with a button to the download page. It never
  downloads anything.

## 1.0.2 — 2026-10-25

- **The skill tree icons are back.** 1.0.1 shipped a `data/skills.json` regenerated by only one of
  the tools that build it, and the step that adds the icons never ran — the 43 nodes that have one
  lost it, and the tree showed none. Nothing failed; the field was simply gone.
- A test now checks that every file in `data/` carries every field the interface reads, and that
  every image they name exists in `build-assets`.

## 1.0.1 — 2026-10-24

First round of fixes after release, driven by two issues and a lot of in-game screenshots.

### What an item shows ([#2](../../issues/2))

Items now show **what they actually do**: the attribute lines and the enhancements per upgrade
level, read from the game's own resources and laid out the way the game lays them out.

- **Armour** is computed and shown per piece. The formula comes from a comment the studio itself
  compiled into the game (`Base Armor = offset + ( gradient * item level )`), with the two
  constants from the same table, and the result was checked against the game on a worn piece: the
  computed value and the one on screen agree.
- **Weapon damage** is computed from `seed × dmgMod × speedMod × (1 + 0.15 × level)` and the
  enhancements that are a fraction of it — the game writes that fraction on screen ("10% of base
  damage"). Checked against a pair of daggers at level 50: the game shows +5.5, this shows +5.5.
- Enhancements that grant **armour or damage of a type** are shown with their value. The armour
  ones are computed at the level of their own row, which is how the game does it.
- Each enhancement row is labelled with the **item level** at that step (251, 252, …), not with
  its index.
- How many enhancement rows appear is the item's **rarity**. A Common item no longer advertises
  the five enhancements of a Legendary one.

### Known limits

- **Bows, staves and wands show less than the game does.** Their own damage distribution is zero:
  they carry no damage, it comes from the projectile. The number shown is only the part that
  comes from the weapon, so a bow reads 21.6 where the game reads 21.5. Melee weapons are exact.
- **The attribute totals on the Character screen are lower than the game's.** They count what the
  skill tree gives. The game also adds the nodes that scale with your Flame level and the bonuses
  from your gear, and neither is stored in the character save. The screen says so.

### Language ([#1](../../issues/1))

Item and skill names follow the language you pick, everywhere. They already did in some places
and not in others: the skill tree tooltip, the item catalogue and its sort order, the gem picker,
the backpack warning, the rejection report and the tree validation messages were all stuck in
Portuguese with the interface in English. Search always worked, because it matches both languages
— which is exactly what the report said.

**Knowledge entries** follow the language too: 6784 of the 8335 are an item or an item's recipe,
and their name now comes from the item table instead of being baked in Portuguese. The rest are
game actions with no item behind them, and the game only ships one name for those.

Skill node **descriptions** are translated too — the game ships its text in 15 languages and the
data only carried the Portuguese one.

A test now sweeps the source and fails on any line that reads the Portuguese field directly.

### Fixes

- **Durations** are in milliseconds and the game switches unit by size: a weapon's attack speed
  read `774s` and now reads `0.8s`; a 90-second effect reads `1:30 m`.
- The **"Item Level"** line is gone from the attribute list. The game keeps it in the tooltip
  header and does not repeat it, and the value stored in the file is the item's *nominal* level —
  so a level-11 axe was announcing 40.
- The equipment doll had the **armour and vanity columns swapped**. Worn armour occupies mask bits
  5 through 9, which were labelled "(2)" — so the left column looked empty and the right one full.
- The detail panel pushed **Duplicate and Remove off the bottom**; it now scrolls, like the game's
  own tooltip.
- The window opens at **1920×1080** (was 1600×900).

### Under the hood

- `data/item-stats.json`: attribute lines, enhancements, damage and armour distributions for 1986
  items, plus the balancing constants (~700 KB).
- `tests/todas-as-armas.mjs` sweeps all 1986 items at three levels in both languages and fails on
  any line without a label, with an invalid number, or with nothing to show. It is the test that
  would have caught the blank enhancement rows on bows.
- 114 assertions across 6 suites.
